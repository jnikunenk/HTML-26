Leikkimielinen Ornn hahmon faniklubin verrkosivusto

1. Mikä oli verkkosivustosi aihe?
    - Ornn hahmon fanisivu

2. Mitä uutta opit tehtävää tehdessäsi
    - Audio ja video upottamista

3. Mikä oli vaikein kohta?
    - Keksiä kaikille tehtävä vaatimuksille sopiva käyttö kohde

4. Minkä HTML-elementin käyttö oli sinulle uusi asia?
    - `<iframe>` elementin

5. Mitä semanttisia HTML-elementtejä käytit?
    - `<header>`
    - `<nav>`
    - `<footer>`
    - `<form>`

6. Miksi käytit juuri näitä elementtejä?
    - Käytän `<header>` elementtiä sivusto otsikkoon
    - Käytän `<nav>` elementtiä sivu ja kohta navigaatioon
    - Käytän `<footer>` elementtiä lisenssi tietojen selventämiseen
    - Käytän `<form>` elementtiä lomakkeessa

7. Mitä HTML-validaattori löysi?
    - youtubesta kopioimassa upotuslinkissä oli vanhentunut atribuutti

8. Millaisia HTML-virheitä korjasit?
    - sivuni hyppäsi suoraan h1 -> h3 koska olin poistanut h2 välistä muuttaessani sivua

9. Mitä teit sivuston saavutettavuuden parantamiseksi?
    - lisäsin `aria-label` atribuutin `<nav>` elementtiin
    - tarkistin sivun lighthousella

10. Mitä tekisit sivustolle seuraavaksi, jos saisit käyttää CSS:ää?
    - rivittäisin elementtejä mukavemmin
